# Ccode 展示与下载官网

## 目标和范围

为 Ccode（安装包产品名 CCode，开发方川升AI）提供中文响应式官网，手机和电脑使用同一网址。采用 AstroWind 的 Astro 静态站基础和区块结构，保留复用代码的 MIT 署名；参考 Xora 的产品展示层次，不复制其素材。主目标为了解产品、查看使用流程、下载安装包。

独立项目放在 `sites/ccode`，拥有自己的依赖和构建；不接入桌面运行时、会话、模型认证或现有 Web 应用。当前任务交付可构建的本地站点；公开域名和安装包 CDN 尚未配置，不擅自提交、推送或上线仓库内容。

## 产品和内容

- 主导航：产品能力、使用流程、下载、常见问题。首屏强调“把想法，变成可交付的作品”。
- 产品能力只介绍已有任务工作台、文件/代码协作、内置任务拆解和自定义模型配置。工作台展示为明确标识的交互示意，不伪装成真实运行结果。
- 首版只提供已存在的 Windows x64 `CCode-3.16.2-win-x64.exe`。不承诺 macOS/Linux/移动应用下载、免费模型额度、自动更新或尚未核实的第三方登录。
- 下载清单为唯一版本来源，包含版本、平台、文件名、大小、SHA-256、URL。通过发布准备命令从指定本地安装包生成；文件不进入 Git。
- 未准备安装包时下载按钮不可点击，并显示“安装包准备中”；不能链接 404 或上游 ZCode 安装包。
- 检测到 Android/iPhone/iPad/iPod（含桌面 UA 的触屏 iPad）时，首屏和下载区显示“手机版待开发”，不展示 Windows 下载按钮、版本标签、复制下载地址或校验值；官网介绍仍正常浏览。根据设备而非视口宽度判断，电脑缩窄窗口仍可下载。检测在 head 内同步执行，避免先展示 Windows 按钮后跳变。禁用 JavaScript 时保留明确标注的 Windows 桌面下载信息。
- FAQ 解释模型需自行配置、安装版与原版独立、更新需重新下载安装，以及移动端访问的含义。

## 视觉和交互

官网是营销内容，不是桌面应用 UI；独立使用命名 CSS token，不改变 DESIGN.md 的应用字号体系。浅色为默认，暖白背景、深墨文字、紫色强调，深色产品展示窗口；支持明暗主题。正文 16px，触控目标至少 44px，明确焦点环，尊重 reduced-motion。断点 640/768/1024/1280，320px 到 1440px 无页面横向溢出。

页面采用首屏与产品示意、能力区、三步上手、下载区、FAQ、页脚。移动导航可展开并用 Escape 关闭；主题开关、演示场景切换、FAQ 和复制链接均有实际行为。禁用脚本时核心介绍、下载链接和 FAQ 仍可使用。演示窗口内部有界、min-height:0、overflow:hidden，不把页面或卡片做成数据滚动容器。

## 所有者与边界

```mermaid
flowchart LR
  A[本地已构建安装包] --> B[发布准备脚本：校验并暂存]
  B --> C[生成下载清单 + 静态下载文件]
  C --> D[Astro 构建时读取]
  D --> E[桌面/手机同一静态官网]
  E --> F[点击链接：下载文件]
```

发布准备脚本是清单唯一写入者；页面只读清单。主题偏好只属于浏览器本地，不接服务端。示意场景只属于展示组件，不承载真实任务或会话。

## 验收

1. 自动化验证缺失安装包、合法安装包生成清单及哈希、非法文件名、文件与清单不匹配时禁止构建。
2. 构建产物引用真实暂存文件，HTTP 下载响应大小与源文件一致；不执行安装包。
3. 浏览器在 320/390/768/1440 宽度验证无横向溢出，手机导航、主题、演示切换、FAQ、复制链接可用。
4. Astro 类型检查和生产构建通过；执行仓库 `pnpm typecheck`、`pnpm lint`、`pnpm architecture:check --changed` 并区分已有问题。
5. 关闭本任务启动的服务；交付截图、源码路径和重启命令。公网部署和真实手机设备验证未执行时明确披露。
