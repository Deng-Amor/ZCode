# 川升前端品牌

## 产品规则
助手对外名称为 CCode，开发方为川升AI。产品界面、自我介绍和欢迎语使用 `CCode`；助手正文中的真实项目名、技术名、引用、代码、路径、链接和历史事实保留 `ZCode`，不得全局替换为 `CCode`。明确询问 CCode 与 ZCode 的关系时，必须保留两个名称并准确说明二者关系；流式末尾的 `Z`、`ZC`、`ZCo`、`ZCod` 暂缓显示直到匹配确定。该规则不更改项目路径、协议标识或供应商配置。
助手正文在客户端 Markdown/Gen UI 展示前不得对 `ZCode` 做全局品牌替换；`智谱 AI`、`智谱AI`、`Zhipu AI`、`ZhipuAI`、`智谱` 和 `Zhipu` 等供应商名称也必须在技术说明、引用、代码、路径、链接和事实回答中保留真实名称。用户输入、工具结果、供应商配置、请求参数和持久化原文不修改。完成态历史消息复用同一保真展示规则，回复复制按钮也复制保真文本。
流式文本使用当前累计正文作纯函数投影，暂缓显示末尾未完成的名称前缀；新片段补齐后再替换，完成或中断时释放不完整尾部，不新增会话状态或改写服务端快照。
产品显示名称统一为“川升”，中英文界面一致。产品 Logo 使用用户提供的透明 PNG，显示时裁去透明边距，保持原比例。深色底使用白色图案，浅色底使用深色图案。

## 所有者与边界
共享 UI 品牌组件拥有 Logo 呈现；本地化文案拥有产品显示名称；Desktop/Web HTML 拥有启动壳与窗口标题。保留内部 ZCode 标识、持久化路径、协议、供应商真实名称、模型名称、法律署名及服务地址。

## 验收
Windows/Linux 原生托盘悬停提示为 `CCode`，右键菜单使用“打开 CCode / Open CCode”和“关于 CCode / About CCode”。这些文案由 shared 的 desktopMenu 本地化表统一提供，不能只修改 React 界面的文案；保留内部消息 ID 兼容现有调用。
Windows 主窗口通过 `setAppDetails` 显式提供与进程一致的 AppUserModelId 和川升 ICO 路径，确保源码版运行时任务栏不回退到 electron.exe 的默认图标。
Windows 窗口、任务栏预览、托盘与安装器图标复用川升品牌资源，使用深色底和白色原图轮廓，保持横向比例。新任务页背景水印直接使用前景色与 12% 不透明度，避免与半透明颜色重复叠加而不可见。
欢迎页、启动壳、标题栏、移动端品牌、关于/引导和发布说明图标展示用户图案。深浅主题均清晰，横向图案不拉伸。可见产品文案显示川升。BigModel/Z.ai 授权和 GLM 模型标识仍准确。执行类型、Lint、架构检查和实际页面检查。
